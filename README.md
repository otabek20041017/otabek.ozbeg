## Overview

otabek.ozbeg is an automation testing framework tailored for web applications, combining Selenium WebDriver, TestNG, Cucumber, and Allure to deliver comprehensive browser-based testing solutions. It supports parallel execution, detailed reporting, and behavior-driven development, making it easier for developers to validate complex user flows and ensure application quality.

**Why otabek.ozbeg?**

This project aims to simplify and enhance web testing workflows. The core features include:

- **🧪🎯** **Test Automation & BDD Integration:** Seamlessly combines Selenium, Cucumber, and TestNG for scalable, maintainable tests.
- **🚀🛠️** **Parallel Execution & Reporting:** Executes tests concurrently with detailed Allure reports for quick insights.
- **🔧📁** **Modular Test Structure:** Organizes test cases for login, search, and content validation, promoting reusability.
- **🌐🖥️** **Environment Consistency:** Ensures reliable setup across different environments for stable test runs.
- **⚙️📊** **Streamlined CI/CD Compatibility:** Easily integrates into continuous deployment pipelines for automated quality checks.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** Java
- **Package Manager:** Maven

### Installation

Build otabek.ozbeg from the source and install dependencies:

1. **Clone the repository:**

    ```sh
    ❯ git clone https://github.com/otabek20041017/otabek.ozbeg
    ```

2. **Navigate to the project directory:**

    ```sh
    ❯ cd otabek.ozbeg
    ```

3. **Install the dependencies:**

**Using [maven](https://maven.apache.org/):**

```sh
❯ mvn install
```

### Usage

Run the project with:

**Using [maven](https://maven.apache.org/):**

```sh
mvn exec:java
```

### Testing

Otabek.ozbeg uses the {__test_framework__} test framework. Run the test suite with:

**Using [maven](https://maven.apache.org/):**

```sh
mvn test
```
